# Split-Flap-Display-Calendar-Build


This project is a mechanical, retro-style calendar inspired by classic train station departure boards. Instead of a digital screen, it uses a series of physical, split-hinged flaps that flip down to display the current date.

The core mechanism is entirely mechanical: to advance the calendar to the next day or month, you simply spin a built-in cog. This rotational movement triggers the flaps to cascade and reveal the updated date, combining tactile mechanical engineering with a vintage aesthetic.
